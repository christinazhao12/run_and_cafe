      Distances are one way, along a walking route calculated from OpenStreetMap data. Cafes without a calculated route show an estimate (straight-line distance plus 25% for the street grid), which tends to run short when a run crosses the river. The route you choose for a run may be longer or shorter.

      An address you search for is sent to OpenStreetMap’s Nominatim search service, and the resulting coordinates go to the FOSSGIS routing server. This page does not store your address.

      Hours, food, and other details are marked only where they have been checked, so a filter leaves out cafes with missing details. Check hours before you go, since several of these places have weekend lines.
