Run to coffee.

Cafes worth finishing a run at, measured one way from Court Square station. Run there, grab a coffee, and take the train home.

    Known for

      Distances are one way, along a walking route calculated from OpenStreetMap data. When a route is unavailable, the page shows an estimate instead (straight-line distance plus 25% for the street grid). The route you choose for a run may be longer or shorter.

      An address you search for is sent to OpenStreetMap’s Nominatim search service, and the resulting coordinates go to the FOSSGIS routing server. This page does not store your address.

      Map data © OpenStreetMap contributors. Routing by the FOSSGIS OSRM demo server. Check hours before you go, since several of these places have weekend lines.
